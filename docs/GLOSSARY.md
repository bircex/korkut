# Glossary

Turkish legal and product terms used throughout Korkut, with short English explanations.

## Courts & institutions

| Term | Meaning |
|---|---|
| **Yargıtay** | Court of Cassation — highest court for civil and criminal matters. |
| **Danıştay** | Council of State — highest administrative court. |
| **Anayasa Mahkemesi** | Constitutional Court (handles individual applications, *bireysel başvuru*). |
| **Uyuşmazlık Mahkemesi** | Jurisdictional Disputes Court — resolves which court has jurisdiction. |
| **UYAP** | National Judiciary Informatics System; **UYAP Emsal** is its precedent database. |
| **KİK** | Public Procurement Authority (Kamu İhale Kurumu). |
| **Rekabet Kurumu** | Competition Authority. |
| **Sayıştay** | Court of Accounts (public-sector audit). |
| **GİB** | Revenue Administration (Gelir İdaresi Başkanlığı) — tax. |
| **KVKK** | Personal Data Protection Authority/Law. |
| **BDDK** | Banking Regulation and Supervision Agency. |
| **Sigorta Tahkim** | Insurance Arbitration Commission. |
| **mevzuat** | Legislation (the body of laws/regulations; `mevzuat.gov.tr`). |

## Casework

| Term | Meaning |
|---|---|
| **dosya** | Case file / matter — the unit a lawyer's work hangs off. |
| **müvekkil** | Client. |
| **dava** | Lawsuit / case. |
| **dava türü** | Case type. |
| **karşı taraf** | Opposing party / counterparty. |
| **esas no** | Court file (docket) number. |
| **duruşma** | Hearing — a court session to attend. |
| **süre** | Procedural deadline — a date by which an act must be done (distinct from a hearing). |
| **cevap süresi** | Deadline to file a reply. |
| **istinaf** | Appeal to a regional court of appeal. |
| **temyiz** | Appeal to the Court of Cassation. |
| **kanun yararına bozma (KYB)** | Appeal "in the interest of law". |

## Documents

| Term | Meaning |
|---|---|
| **dilekçe** | Petition / pleading — a formal court submission. |
| **sözleşme** | Contract. |
| **ihtarname** | Formal notice / warning letter. |
| **deliller** | Evidence. |
| **görev / yetki** | Subject-matter jurisdiction / territorial jurisdiction. |
| **UDF** | The UYAP document format (a national e-filing format); Korkut exports drafts to UDF and DOCX. |
